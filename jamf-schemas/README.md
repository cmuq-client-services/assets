# Jamf custom-settings schemas

Unmodified copies of schemas that Jamf Pro serves for its "Application & Custom Settings > External Applications" form.
Kept here so a profile can be rebuilt from a Custom Schema (and diffed against future Jamf versions).

| Domain | Version | File | Retrieved |
|---|---|---|---|
| com.jamf.setupchecklist | 1.1.0 | setupchecklist/1.1.0/SetupChecklist.json | 2026-10-26 (Jamf Pro schema-detail API, bucket prod-custom-setting-schemas) |

The file is the inner `schema` object of the API response, pretty-printed; content is Jamf's, not ours.
